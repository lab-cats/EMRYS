# Validation infrastructure

The stable `emrys.libraries.validation` facade provides validation errors,
stable input snapshots, report rows/schema, transactional publication, strict
TSV helpers, and dry-run/execute lifecycle mechanics. Consuming owners retain
input selection, check IDs, external commands, evidence interpretation, and
scientific claims.

Known same-size/restored-mtime input and publication-recovery gaps remain
characterized defects. A fix must preserve bytes, names, input stability,
no-follow/no-clobber behavior, signals, rollback evidence, and unrelated files
across every consumer; this transaction is not automatically suitable for
unrelated publishers.
