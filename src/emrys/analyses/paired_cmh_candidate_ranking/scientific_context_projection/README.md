# Scientific-context projection owner

Analysis `10` consumes the admitted Step 09 result trio, FASTA/FAI, and fixed
PUM motif policy to publish five figure-ready context artifacts. The producer
is [`scientific_context_projection.sh`](scientific_context_projection.sh), its
computation is [`scientific_context_projection.R`](scientific_context_projection.R),
and validation is `emrys validate scientific-context-projection`.

[`CONTRACT.md`](CONTRACT.md) owns exact orientation, population, motif,
enrichment, transaction, and validation semantics. The projection is not a
report renderer, transcript-strand inference, binding claim, editing-site
adjudication, or biological proof. Normal execution belongs to the immutable
`emrys run`/`resume` journey described in the
[runbook](../../../../../docs/operations/RUNBOOK.md#project-and-run-operations).
