# Orchestration schemas v1

These Draft 2020-12 JSON files define current Project,
Analysis/Execution-Plan/Run, reference and module policy, Run locks, workflow
Attempts, task starts, terminal task results and verified markers, and reporting
starts and verified records, using one shared definition resource.

Workflow profiles and scientific Attempt receipts live in v2; combined execution
profiles and resource policy live in v3. The
[orchestration contract](../../../orchestration/README.md) owns
schema selection, canonical JSON, and validation. This directory only stores
packaged resources.
