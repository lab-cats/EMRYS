# Orchestration schemas v3

These files define the current combined execution profile and its symbolic
Run-bound resource values. Attempts resolve those resource declarations against
their allocations and retain both the declaration and resolution.

The [orchestration contract](../../../orchestration/README.md) selects schemas,
defines canonical JSON, and validates record meaning. The
[version rules](../../README.md#version-and-identity-rules) apply to changes.
