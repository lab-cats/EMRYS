# Detailed decisions

This directory holds focused rationale behind the durable summaries in
[`DECISIONS.md`](../DECISIONS.md). The summary is the entry point; these records
provide subject detail without owning current status or commands.

- [`repository-and-delivery.md`](repository-and-delivery.md) — repository
  ownership, development, configuration, and delivery boundaries.
- [`execution-evidence-and-reporting.md`](execution-evidence-and-reporting.md)
  — execution safety, evidence, publication, recovery, and reporting.
- [`scientific-pipeline.md`](scientific-pipeline.md) — scientific workflow and
  artifact-policy decisions.
- [`platform-direction.md`](platform-direction.md) — product and future-platform
  direction.

Accepted open outcomes and acceptance remain in the
[findings matrix](../../tasks/backlog_matrix.md). Unsliced architecture choices
remain temporarily in the
[architecture campaign](../../tasks/architecture_campaign.md).
