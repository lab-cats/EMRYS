# NORAD glossary

This is the canonical maintainer-facing reference for abbreviations, formats,
tools, methods, and project-specific evidence language used across NORAD. It
explains what a term means here and links to the owner of detailed behavior; it
does not replace schemas, procedures, scientific policy, or tool manuals.

The entries are alphabetized case-insensitively. Categories are navigational:
`format`, `tool`, `method`, `field`, `schema`, `source`, `project contract`,
`operation`, `scientific term`, and `evidence state`.

| Term | Category | NORAD meaning and canonical detail |
| --- | --- | --- |
| **A-to-I RNA editing** | scientific term | **Adenosine-to-inosine RNA editing**. Sequencing-based candidate workflows commonly observe inosine as guanosine, but NORAD outputs remain CMH-ranked candidates until separate scientific evidence supports interpretation. See the [scientific boundary](../architecture/ARCHITECTURE.md#scientific-boundary). |
| **AD** | field | **Alternate depth** in NORAD Step `08`/`09` tables: the count supporting the alternate allele. NORAD checks that AD does not exceed DP and that AF agrees with AD/DP. This is narrower than every use of `AD` allowed by VCF. See the [Step `09` implementation](../../src/norad/analyses/paired_cmh_candidate_ranking/step_09_cmh_editing_site_calling.R). |
| **AF** | field | **Allele fraction**, calculated as AD/DP when depth is available. It is a count-derived measure, not proof of RNA editing. See the [Step `09` implementation](../../src/norad/analyses/paired_cmh_candidate_ranking/step_09_cmh_editing_site_calling.R). |
| **artifact** | project contract | A declared workflow output represented with identity, scope, status, provenance, and evidence metadata. An artifact record describes evidence; schema validity alone does not prove the underlying computation. See the [artifact-record schema](../../src/norad/contracts/schemas/artifacts/v1/artifact_record.schema.json) and [artifact layer](../architecture/ARCHITECTURE.md#artifact-and-summary-layer). |
| **artifact adapter** | project contract | A read-only translator from explicit native outputs into the structured artifact contract. It must not mutate native outputs or promote evidence state. See [Decouple reporting from computation](../design/DECISIONS.md#decouple-reporting-from-computation). |
| **attempt** | project contract | One recorded execution try with its own identity, state, timestamps, exit information, evidence, warnings, errors, and optional predecessor. Retries create attempts rather than changing run identity. See the [common schema](../../src/norad/contracts/schemas/artifacts/v1/common.schema.json) and [intake decision](../design/DECISIONS.md#use-yaml-run-requests-with-tsv-sample-manifests). |
| **BAI** | format | **BAM index**, the companion index used for random access to a BAM. NORAD treats a BAM/BAI pair as a coupled output where required. See the [canonical BAM boundary](../design/DECISIONS.md#make-step-02-the-canonical-bam-boundary). |
| **BAM** | format | **Binary Alignment/Map**, the binary representation of SAM alignments. A valid container alone does not establish correct sort order, read groups, sample identity, or scientific validity. See the [reference and BAM decisions](../design/DECISIONS.md#reference-and-bam-pipeline). |
| **bcftools** | tool | The command-line toolkit used for cohort mpileup, filtering, VCF queries, and index-aware operations in Step `07`. It is a tool name, not a NORAD acronym. See the [Step `07` procedure](../operations/RUNBOOK.md#step-07-bcftools-mpileup). |
| **BED** | format | **Browser Extensible Data**, a tabular genomic-interval format. NORAD accepts explicitly declared BED-like selector inputs where the relevant contract permits them; BED and BED12 are not interchangeable. See the [Step `07` selector contract](../design/DECISIONS.md#run-step-07-cohort-wide-and-manifest-partitioned). |
| **BED12** | format | The 12-column BED form used by NORAD to represent transcript exon blocks for RSeQC. It is derived from the declared GTF and validated for structure and agreement. See [Generate BED12 from GTF](../design/DECISIONS.md#generate-bed12-from-gtf). |
| **BGZF** | format | **Blocked GNU Zip Format**, the block-compressed container commonly underlying BAM and compressed genomic files. Recognizing BGZF bytes is a container check, not semantic validation of an alignment. See the [Step `01` validator](../../src/norad/stages/star_alignment/validator.py), exposed as `python -I -m norad validate star-alignment`. |
| **BH** | method | **Benjamini-Hochberg** multiple-testing adjustment. Step `09` applies one global BH family to successfully tested target candidates; the resulting adjusted value is not independent biological validation. See [Use one paired CMH and global BH family](../design/DECISIONS.md#use-one-paired-cmh-and-global-bh-family). |
| **`biological_interpretation_ready`** | evidence state | Reserved state for a future, separately approved scientific policy with explicit exit criteria. Current tools must reject requests for this state; it is not a stronger spelling of exploratory review. See [Preserve two post-review states](../design/DECISIONS.md#preserve-two-post-review-states). |
| **canonical run summary** | project contract | The single validated, versioned structured entry point for reporting one immutable run contract, including expected scopes and explicit missing or incomplete evidence. Renderers consume it rather than discovering native inputs. See the [run-summary schema](../../src/norad/contracts/schemas/artifacts/v1/run_summary.schema.json) and [reporting boundary](../architecture/ARCHITECTURE.md#reporting-boundary). |
| **CLI** | operation | **Command-line interface**. NORAD public CLIs validate explicit arguments, default to dry-run where specified, expose `--help`, and use defined stdout/stderr and exit behavior. Exact invocations belong in the [runbook](../operations/RUNBOOK.md). |
| **cluster dry-run validated** | evidence state | The cluster-facing command or job contract was validated without executing the heavy workflow. It does not establish scheduler completion, runtime success, or cluster proof. See the [evidence boundary](../../AGENTS.md#evidence-language). |
| **cluster-proven** | evidence state | Scheduler state, logs, validation commands, and outputs were inspected and support the claim. Tool availability, mocked execution, local runtime success, or a dry-run is insufficient. See the [evidence boundary](../../AGENTS.md#evidence-language). |
| **CMH** | method | **Cochran-Mantel-Haenszel** stratified test. NORAD Step `09` uses declared replicate strata and a two-sided continuity-corrected test, then applies the global BH family. See [Use one paired CMH and global BH family](../design/DECISIONS.md#use-one-paired-cmh-and-global-bh-family). |
| **CMH-ranked candidate** | scientific term | A candidate row ranked by the Step `09` CMH workflow and its declared filters. The required phrase is **CMH-ranked candidate**, not “validated editing site”; computational ranking does not settle biological interpretation. See the [scientific boundary](../architecture/ARCHITECTURE.md#scientific-boundary). |
| **CRAM** | format | A compressed alignment format related to SAM/BAM and typically dependent on a reference for decoding. It is prohibited from Git like BAM and other large runtime data; NORAD's implemented canonical alignment boundary is BAM/BAI. See the [data policy](../../README.md#data-and-git-policy). |
| **CSI** | format | **Coordinate-Sorted Index**, an index format that some BAM-index validators accept alongside BAI signatures. Acceptance of the container does not change the stage's declared output basename or BAM/BAI contract. See the [Step `02` validator](../../src/norad/stages/canonical_bam/validator.py), exposed as `python -I -m norad validate canonical-bam`. |
| **CSS** | format | **Cascading Style Sheets**, the static styling language used by the HTML report template. CSS affects presentation only and cannot change report inputs or evidence state. See the [reporting boundary](../architecture/ARCHITECTURE.md#reporting-boundary). |
| **CSU** | operation | **Colorado State University**, the HPC/SLURM environment targeted by the repository's cluster wrappers and operational guidance. Local or mocked success must not be presented as CSU cluster proof. See [Develop locally and scale through SLURM](../design/DECISIONS.md#develop-locally-and-scale-through-slurm). |
| **DAG** | project contract | **Directed acyclic graph**, the target representation of semantic stage dependencies and branch points. The exact semantic DAG remains future design and does not replace the implemented numeric pipeline. See [Identify stages semantically and order them with a DAG](../design/DECISIONS.md#identify-stages-semantically-and-order-them-with-a-dag). |
| **DICT** | format | Sequence dictionary sidecar for a reference FASTA, containing ordered contig identity and length metadata used by GATK-era tooling. NORAD validates agreement with FASTA, FAI, GTF, BED12, and STAR metadata rather than regenerating it during inspection. See [Reconcile references without repair](../design/DECISIONS.md#reconcile-references-without-repair). |
| **DP** | field | **Depth**, the total read count used with alternate depth in NORAD Step `08`/`09` tables. AF must reconcile with AD/DP where present. See the [Step `09` implementation](../../src/norad/analyses/paired_cmh_candidate_ranking/step_09_cmh_editing_site_calling.R). |
| **dry-run / execute** | operation | Dry-run validates and prints the resolved plan without publishing final outputs; execute performs the declared work and publication. Dry-run success is not runtime evidence. See [Default to dry-run](../design/DECISIONS.md#default-to-dry-run). |
| **evidence state** | project contract | A deliberately separated claim about implementation, testing, runtime, cluster execution, scientific review, or biological readiness. Moving one dimension does not promote the others. See [Separate computational proof and scientific interpretation](../design/DECISIONS.md#separate-computational-proof-and-scientific-interpretation). |
| **`evidence_incomplete`** | evidence state | The exact public-schema science status used when required scientific evidence or review completion is absent. A structurally complete summary may lawfully retain this state. See the [run-summary schema](../../src/norad/contracts/schemas/artifacts/v1/run_summary.schema.json). |
| **FAI** | format | **FASTA index**, a text sidecar recording ordered sequence names, lengths, and byte offsets. NORAD compares its contig names and lengths with the FASTA and DICT. See [Treat FASTA sidecars as Step `00c`](../design/DECISIONS.md#treat-fasta-sidecars-as-step-00c). |
| **FASTA** | format | A reference sequence text format named for the FASTA software family; NORAD does not expand it as an acronym. The declared FASTA anchors reference identity, and its sidecars and annotations must reconcile to its contig universe. See [Use the Novogene-provided reference](../design/DECISIONS.md#use-the-novogene-provided-reference). |
| **FASTQ** | format | A sequence-read format carrying base calls and per-base quality characters. NORAD's current workflow accepts explicit paired R1/R2 FASTQ inputs from the sample manifest; filenames do not define pairing. See the [identity boundary](../architecture/ARCHITECTURE.md#identity-and-explicit-input-boundaries). |
| **FDR** | method | **False discovery rate**. In the Step `09` column `cmh_fdr_bh`, it is the BH-adjusted CMH p-value across the declared tested family, not a claim that the candidate is true or biologically validated. See [Use one paired CMH and global BH family](../design/DECISIONS.md#use-one-paired-cmh-and-global-bh-family). |
| **`FWD_like` / `REV_like`** | project contract | Neutral labels for mechanically separated read-orientation groups. They are not transcript-strand, biological sense/antisense, or validated editing-direction labels. See [Separate mechanical orientation from biological strand](../design/DECISIONS.md#separate-mechanical-orientation-from-biological-strand). |
| **GATK** | tool | **Genome Analysis Toolkit**. NORAD uses its RNA-seq-oriented operations and reference conventions in bounded stages such as `SplitNCigarReads`; availability or a version check is not proof that a stage ran. See the [GATK runtime procedure](../operations/RUNBOOK.md#gatk). |
| **GTF** | format | **Gene Transfer Format**, the declared gene/transcript annotation used to derive BED12 and annotate candidates. NORAD records its provenance and checks contig agreement; it does not infer annotation identity from filenames. See [Generate BED12 from GTF](../design/DECISIONS.md#generate-bed12-from-gtf). |
| **HPC** | operation | **High-performance computing**. In NORAD this usually refers to the CSU cluster environment where heavy work runs through SLURM jobs, not on the login node. See the [cluster execution pattern](../operations/RUNBOOK.md#cluster-execution-pattern). |
| **HTML** | format | **HyperText Markup Language**, one static report-bundle output. Rendering projects the canonical summary and does not run analysis or promote evidence. See the [reporting boundary](../architecture/ARCHITECTURE.md#reporting-boundary). |
| **implemented locally** | evidence state | The behavior exists in local source history. This phrase alone makes no claim about fixture tests, real runtime, cluster execution, scientific review, or biological interpretation. See the [evidence boundary](../../AGENTS.md#evidence-language). |
| **JSON / JSON Schema** | schema | **JavaScript Object Notation** and its machine-readable validation vocabulary. NORAD's versioned closed JSON Schemas define structured artifact/report contracts; schema validity does not prove computation or science. See [Use versioned closed schemas](../design/DECISIONS.md#use-versioned-closed-schemas). |
| **locally fixture-tested** | evidence state | Focused local checks passed using tiny synthetic fixtures, mocks, or test doubles as declared. This is neither real-runtime testing nor cluster proof. See the [evidence boundary](../../AGENTS.md#evidence-language). |
| **manifest** | project contract | An explicit table that declares identities, ordering, pairing, partitions, or other repeated inputs. The sample manifest owns sample metadata; the partition manifest owns Step `07` selection. NORAD does not infer these facts from filenames or globs. See the [identity boundary](../architecture/ARCHITECTURE.md#identity-and-explicit-input-boundaries). |
| **mechanical orientation** | project contract | A grouping derived from alignment flags and the provisional orientation policy. It remains distinct from library strandedness, transcript strand, and biological sense/antisense interpretation. See the [scientific boundary](../architecture/ARCHITECTURE.md#scientific-boundary). |
| **NA** | project contract | A literal sentinel used by exact TSV contracts for a field-specific missing, unavailable, or not-applicable value. The owning contract determines which meaning is allowed; `NA` is not interchangeable with zero or an empty field. See the [structured-artifact decisions](../design/DECISIONS.md#structured-artifacts-and-reporting). |
| **NCBI** | source | **National Center for Biotechnology Information**, the external archive/provider named in NORAD's future public reference and read-acquisition design. NCBI acquisition is not part of the current implemented workflow. See [Prioritize local FASTQ and registered references before public acquisition](../design/DECISIONS.md#prioritize-local-fastq-and-registered-references-before-public-acquisition). |
| **no-clobber** | operation | A publication rule that refuses to overwrite an incompatible existing final artifact or transaction. Compatible, explicitly supported upgrades remain separate contract cases. See the [native transaction boundary](../architecture/ARCHITECTURE.md#native-artifact-transactions). |
| **NORAD** | project contract | The repository/project name for this CSU HPC RNA-seq and RNA-editing workflow. The repository does not define a spelled-out expansion; do not infer one. See the [project overview](../../README.md). |
| **owned lock** | operation | A lock whose creator records and verifies ownership before cleanup. If ownership or rollback cannot be proved, NORAD preserves the lock and recovery evidence instead of guessing. See [Preserve recovery evidence](../design/DECISIONS.md#preserve-recovery-evidence). |
| **PDF** | format | **Portable Document Format**, retained for declared scientific-analysis plot artifacts such as Step `09`/`09c` figures. PDF is not a run-report format, and a valid plot file is not computational or scientific proof by itself. See [Render deterministic, static reports](../design/DECISIONS.md#render-deterministic-static-reports). |
| **Picard** | tool | A Java-based genomics toolkit used by NORAD for duplicate marking and metrics. The current policy marks duplicates rather than removing them. See [Mark rather than remove duplicates](../design/DECISIONS.md#mark-rather-than-remove-duplicates). |
| **provenance** | project contract | Recorded origin and identity evidence such as explicit paths, hashes, source/release metadata, producer identity, and attempt history. A filename or colocated directory alone is not provenance. See [Reconcile references without repair](../design/DECISIONS.md#reconcile-references-without-repair). |
| **QC** | method | **Quality control**, a measured check or metric on data or execution. QC can expose integrity, mapping, orientation, or duplication evidence; passing QC does not by itself prove the complete workflow or a biological conclusion. See [Keep QC and downstream transformation as separate consumers](../design/DECISIONS.md#keep-qc-and-downstream-transformation-as-separate-consumers). |
| **R1 / R2** | scientific term | The first and second reads (mates) of one paired-end sequencing fragment. The sample manifest declares each pair; NORAD does not infer pairing from filenames. See the [identity boundary](../architecture/ARCHITECTURE.md#identity-and-explicit-input-boundaries). |
| **real-runtime tested** | evidence state | The relevant non-mocked runtime and dependencies executed against declared local test inputs. It remains distinct from cluster execution, production data, scientific review, and biological validation. See the [evidence boundary](../../AGENTS.md#evidence-language). |
| **receipt / receipt-last publication** | project contract | A deterministic summary or receipt published only after all other members of a multi-file transaction validate. Its presence marks transaction completion; it does not prove the scientific meaning of the contents. See [Publish validated transactions](../design/DECISIONS.md#publish-validated-transactions). |
| **renv** | tool | The R dependency-environment manager used only through NORAD's opt-in repository activation. Restoration is explicit; scripts and tests must not bootstrap packages. It is a tool name, not a NORAD acronym. See [Guard the repository-local R environment](../design/DECISIONS.md#guard-the-repository-local-r-environment). |
| **RG / read group** | field | SAM/BAM header and record metadata that binds alignments to the declared sample/library/platform identity. NORAD validates the `@RG` header and per-record `RG` tag; it is unrelated to `FWD_like`/`REV_like` mechanical orientation. See [Make Step `02` the canonical BAM boundary](../design/DECISIONS.md#make-step-02-the-canonical-bam-boundary). |
| **RNA editing** | scientific term | A post-transcriptional RNA sequence change relative to the encoded reference. NORAD ranks sequencing-derived candidates; its computational outputs are not by themselves validated editing events. See the [scientific boundary](../architecture/ARCHITECTURE.md#scientific-boundary). |
| **RNA-seq** | scientific term | **RNA sequencing**. NORAD is a manifest-driven RNA-seq/RNA-editing workflow spanning reference preparation, alignment, QC, candidate ranking, evidence assembly, and reporting. See the [compute pipeline](../architecture/ARCHITECTURE.md#compute-pipeline). |
| **rollback** | operation | Restoration of the prior published state after a failed multi-file publication attempt. Incomplete rollback is an unsafe recovery state whose locks and evidence must be preserved. See [Preserve recovery evidence](../design/DECISIONS.md#preserve-recovery-evidence). |
| **RSeQC** | tool | **RNA-seq Quality Control**, the toolkit used for mechanical library-orientation fractions. Its labels and fractions do not by themselves establish biological sense/antisense. See the [Step `03` procedure](../operations/RUNBOOK.md#step-03-rseqc-strandedness--orientation-inference). |
| **run contract** | project contract | The immutable, normalized, identity-bound description of one run's declared policy and inputs. Retries create attempts under the same identity rather than silently changing the contract. See [Use YAML run requests with TSV sample manifests](../design/DECISIONS.md#use-yaml-run-requests-with-tsv-sample-manifests). |
| **runtime validation blocked** | evidence state | Required runtime validation could not complete because a named dependency or environment condition prevented evaluation. This is neither a pass nor proof of computational failure. See the [evidence boundary](../../AGENTS.md#evidence-language). |
| **SAM** | format | **Sequence Alignment/Map**, the text alignment format corresponding to BAM. NORAD avoids large default SAM outputs and publishes the declared canonical BAM/BAI boundary instead. See the [compute pipeline](../architecture/ARCHITECTURE.md#compute-pipeline). |
| **samtools** | tool | The alignment-file toolkit used for sorting, read-group handling, indexing, splitting, querying, and integrity checks. It is a tool name, not an acronym. See the [Step `02` procedure](../operations/RUNBOOK.md#step-02-canonical-sort-read-group-tagging-and-bam-indexing). |
| **schema** | schema | A versioned, closed machine contract for allowed structure and values. Passing schema validation establishes conformance to that structure, not computation, scientific review, or biological validity. See [Use versioned closed schemas](../design/DECISIONS.md#use-versioned-closed-schemas). |
| **`science_review_complete_exploratory`** | evidence state | Exact public-schema state for a completed but provisional scientific evidence review. It does not authorize biological interpretation and remains below the reserved ready state. See [Preserve two post-review states](../design/DECISIONS.md#preserve-two-post-review-states). |
| **scientific evidence incomplete** | evidence state | Human-readable evidence-boundary phrase indicating that the available material does not support a completed scientific review or biological conclusion. Structured summaries use the exact value `evidence_incomplete`. See the [scientific exit boundary](../design/PIPELINE_PLAN.md#scientific-exit-boundary). |
| **SHA-256** | method | **Secure Hash Algorithm 256-bit**, used to bind files and contracts to exact bytes. A matching hash establishes byte identity for the compared object, not correctness or scientific validity. See [Require explicit evidence relationships](../design/DECISIONS.md#require-explicit-evidence-relationships). |
| **SLURM** | tool | The **Slurm Workload Manager**, used to submit and inspect CSU cluster jobs. NORAD wrappers remain thin, validate execution mode, and delegate analysis to scripts. See the [cluster execution pattern](../operations/RUNBOOK.md#cluster-execution-pattern). |
| **SNV** | scientific term | **Single-nucleotide variant**, a record with one reference base and one alternate base. Step `08` counts and excludes unsupported non-SNV alleles rather than silently coercing them. See [Consume only declared Step `07` transactions in Step `08`](../design/DECISIONS.md#consume-only-declared-step-07-transactions-in-step-08). |
| **SRA** | source | **Sequence Read Archive**, NCBI's sequencing-read archive and a future NORAD read-acquisition source. Any SRA-to-FASTQ materialization belongs to a separate future adapter, not the current pipeline. See [Prioritize local FASTQ and registered references before public acquisition](../design/DECISIONS.md#prioritize-local-fastq-and-registered-references-before-public-acquisition). |
| **staging** | operation | Writing a run-token-specific temporary replacement before validation and publication. A staged file is not a final output or completion marker. See the [native transaction boundary](../architecture/ARCHITECTURE.md#native-artifact-transactions). |
| **STAR** | tool | **Spliced Transcripts Alignment to a Reference**, the aligner and genome-index format used in Steps `00a` and `01`. NORAD validates the declared index and output set separately from tool availability. See the [compute pipeline](../architecture/ARCHITECTURE.md#compute-pipeline). |
| **transaction** | project contract | A coupled set of outputs that is validated and published as one recoverable unit, with its receipt or summary last. Individual member presence does not establish transaction completion. See [Publish validated transactions](../design/DECISIONS.md#publish-validated-transactions). |
| **TSV** | format | **Tab-separated values**, the preferred explicit table format for manifests, receipts, and deterministic projections. Each consumer owns an exact header and field contract; “TSV” alone does not imply interchangeability. See [Use TSV manifests](../design/DECISIONS.md#use-tsv-manifests). |
| **UTF-8** | format | **Unicode Transformation Format, 8-bit**, the required text encoding for deterministic NORAD JSON/TSV and report inputs where specified. Encoding conformance does not establish semantic validity. See [Use versioned closed schemas](../design/DECISIONS.md#use-versioned-closed-schemas). |
| **VCF** | format | **Variant Call Format**, the declared multi-sample variant/candidate interchange used between Steps `07` and `08`. NORAD validates headers, sample order, selectors, counts, and hashes before semantic parsing. See [Consume only declared Step `07` transactions in Step `08`](../design/DECISIONS.md#consume-only-declared-step-07-transactions-in-step-08). |
| **YAML** | format | **YAML Ain't Markup Language**, the selected future run-request format for policy and explicit paths; repeated sample metadata remains in TSV. This intake contract is target architecture, not current implemented CLI behavior. See [Use YAML run requests with TSV sample manifests](../design/DECISIONS.md#use-yaml-run-requests-with-tsv-sample-manifests). |

## Coverage and update rule

Candidate discovery scans tracked documentation and public interfaces for
recurring abbreviations and project language. The glossary intentionally
excludes task IDs, fixture/sample IDs, file-local constants, shell variables,
generic syntax tokens, and ordinary filenames unless they have a distinct
maintainer-facing meaning. It also does not copy complete schema enums or
field rosters; the versioned schemas remain authoritative.

Add or revise an entry when a term recurs across owners, appears in a public
interface, or can plausibly be mistaken for a stronger evidence or scientific
claim. Verify the meaning against the canonical document, schema, or
implementation; keep the entry concise and alphabetized; add only selective
inbound links where the term otherwise blocks understanding; and run the
documentation gate. Put procedures in the runbook, mutable status in the
handoff or pipeline plan, and scientific policy in the decision owner rather
than duplicating them here.
