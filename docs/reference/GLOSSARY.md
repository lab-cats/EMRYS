# EMRYS glossary

This is the canonical maintainer-facing reference for abbreviations, formats,
tools, methods, and project-specific evidence language used across EMRYS. It
explains what a term means here and links to the owner of detailed behavior; it
does not replace schemas, procedures, scientific policy, or tool manuals.

The entries are alphabetized case-insensitively. Categories are navigational:
`format`, `tool`, `method`, `field`, `schema`, `source`, `project contract`,
`operation`, `scientific term`, and `evidence state`.

| Term | Category | EMRYS meaning and canonical detail |
| --- | --- | --- |
| **A-to-I RNA editing** | scientific term | **Adenosine-to-inosine RNA editing**. Sequencing-based candidate workflows commonly observe inosine as guanosine, but EMRYS outputs remain CMH-ranked candidates until separate scientific evidence supports interpretation. See the [evidence and external-interpretation boundary](../design/decisions/execution-evidence-and-reporting.md#evidence-and-external-interpretation). |
| **AD** | field | **Alternate depth** in EMRYS Step `08`/`09` tables: the count supporting the alternate allele. EMRYS checks that AD does not exceed DP and that AF agrees with AD/DP. This is narrower than every use of `AD` allowed by VCF. See the [Step `09` implementation](../../src/emrys/analyses/paired_cmh_candidate_ranking/step_09_cmh_editing_site_calling.R). |
| **AF** | field | **Allele fraction**, calculated as AD/DP when depth is available. It is a count-derived measure, not proof of RNA editing. See the [Step `09` implementation](../../src/emrys/analyses/paired_cmh_candidate_ranking/step_09_cmh_editing_site_calling.R). |
| **Analysis** | project contract | One named, content-derived scientific definition within a Project. Its human name selects it but does not enter its immutable identity. See the [public application model](../architecture/ARCHITECTURE.md#public-application-model). |
| **analysis module** | project contract | An explicitly selected installed computation provider that contributes closed scientific configuration, typed downstream artifacts, one Step `09` task, and optional Step `10` to an immutable Run. It inherits EMRYS task, validation, publication, recovery, logging, and Results semantics; it is not a workflow engine or mutable plugin registry. See the [analysis-module contract](../../src/emrys/analyses/README.md). |
| **artifact** | project contract | A declared workflow output represented with identity, scope, status, provenance, and evidence metadata. An artifact record describes evidence; schema validity alone does not prove the underlying computation. See the [artifact-record schema](../../src/emrys/contracts/schemas/artifacts/v2/artifact_record.schema.json) and [reporting owner](../../src/emrys/reporting/README.md). |
| **artifact adapter** | project contract | A read-only translator from explicit native outputs into the structured artifact contract. It must not mutate native outputs or promote evidence state. See the [reporting owner](../../src/emrys/reporting/README.md). |
| **Attempt** | project contract | One execution or resume try beneath an immutable Run. It records placement and operational state without rewriting the Run; retries create new Attempts. See the [task and Attempt lifecycle](../../src/emrys/orchestration/run_coordinator/CONTRACT.md#task-and-attempt-lifecycle). |
| **BAI** | format | **BAM index**, the companion index used for random access to a BAM. EMRYS treats a BAM/BAI pair as a coupled output where required. See the [canonical BAM boundary](../design/decisions/scientific-pipeline.md#make-step-02-the-canonical-bam-boundary). |
| **BAM** | format | **Binary Alignment/Map**, the binary representation of SAM alignments. A valid container alone does not establish correct sort order, read groups, sample identity, or scientific validity. See the [reference and BAM decisions](../design/decisions/scientific-pipeline.md#reference-and-bam-pipeline). |
| **bcftools** | tool | The command-line toolkit used for cohort mpileup, filtering, VCF queries, and index-aware operations in Step `07`. It is a tool name, not an EMRYS acronym. See the [Step `07` owner](../../src/emrys/stages/partitioned_cohort_mpileup/README.md). |
| **BED** | format | **Browser Extensible Data**, a tabular genomic-interval format. EMRYS accepts explicitly declared BED-like selector inputs where the relevant contract permits them; BED and BED12 are not interchangeable. See the [Step `07` decision](../design/decisions/scientific-pipeline.md#run-step-07-cohort-wide-and-manifest-partitioned). |
| **BED12** | format | The 12-column BED form used by EMRYS to represent transcript exon blocks for RSeQC. It is derived from the declared GTF and validated for structure and agreement. See [Generate BED12 from GTF](../design/decisions/scientific-pipeline.md#generate-bed12-from-gtf). |
| **BGZF** | format | **Blocked GNU Zip Format**, the block-compressed container commonly underlying BAM and compressed genomic files. Recognizing BGZF bytes is a container check, not semantic validation of an alignment. See the [Step `01` validator](../../src/emrys/stages/star_alignment/validator.py), exposed as `emrys validate star-alignment`. |
| **BH** | method | **Benjamini-Hochberg** multiple-testing adjustment. Step `09` applies one global BH family to successfully tested target candidates; the resulting adjusted value is not independent biological validation. See [Use one paired CMH and global BH family](../design/decisions/scientific-pipeline.md#use-one-paired-cmh-and-global-bh-family). |
| **canonical run summary** | project contract | The single validated, versioned structured entry point for reporting one immutable Run, including expected computational scopes and explicit missing or incomplete artifacts. Renderers consume it rather than discovering native inputs. The flat paired-CMH path uses [v2](../../src/emrys/contracts/schemas/artifacts/v2/run_summary.schema.json); explicit modules use [v3](../../src/emrys/contracts/schemas/artifacts/v3/run_summary.schema.json). See the [reporting owner](../../src/emrys/reporting/README.md). |
| **CLI** | operation | **Command-line interface**. EMRYS public CLIs validate explicit arguments, default to dry-run where specified, expose `--help`, and use defined stdout/stderr and exit behavior. Exact invocations belong in the [runbook](../operations/RUNBOOK.md). |
| **cluster dry-run validated** | evidence state | The cluster-facing command or job contract was validated without executing the heavy workflow. It does not establish scheduler completion, runtime success, or cluster proof. See the [evidence guard](../../AGENTS.md#evidence-guard). |
| **cluster-proven** | evidence state | Scheduler state, logs, validation commands, and outputs were inspected and support the claim. Tool availability, mocked execution, local runtime success, or a dry-run is insufficient. See the [evidence guard](../../AGENTS.md#evidence-guard). |
| **CMH** | method | **Cochran-Mantel-Haenszel** stratified test. EMRYS Step `09` uses declared replicate strata and a two-sided continuity-corrected test, then applies the global BH family. See [Use one paired CMH and global BH family](../design/decisions/scientific-pipeline.md#use-one-paired-cmh-and-global-bh-family). |
| **CMH-ranked candidate** | scientific term | A candidate row ranked by the built-in paired-CMH Analysis and its declared filters. The required phrase is **CMH-ranked candidate**, not “validated editing site”; computational ranking does not settle biological interpretation. See the [evidence and external-interpretation boundary](../design/decisions/execution-evidence-and-reporting.md#evidence-and-external-interpretation). |
| **CRAM** | format | A compressed alignment format related to SAM/BAM and typically dependent on a reference for decoding. It is prohibited from Git like BAM and other large runtime data; EMRYS's implemented canonical alignment boundary is BAM/BAI. See the [data policy](../../README.md#license-and-data-policy). |
| **CSI** | format | **Coordinate-Sorted Index**, an index format that some BAM-index validators accept alongside BAI signatures. Acceptance of the container does not change the stage's declared output basename or BAM/BAI contract. See the [Step `02` validator](../../src/emrys/stages/canonical_bam/validator.py), exposed as `emrys validate canonical-bam`. |
| **CSS** | format | **Cascading Style Sheets**, the static styling language used by the HTML report template. CSS affects presentation only and cannot change report inputs or evidence state. See the [reporting owner](../../src/emrys/reporting/README.md). |
| **CSU** | operation | **Cleveland State University**, whose [Viking cluster](https://academic.csuohio.edu/adam/how-to-access-the-viking-cluster/) is the institutional HPC/Slurm environment targeted by the repository's site guidance. Hosted disposable-Slurm or local success must not be presented as CSU site proof. See [Local development, Slurm production](../design/decisions/repository-and-delivery.md#local-development-slurm-production). |
| **DAG** | project contract | **Directed acyclic graph**, the representation of semantic owner dependencies and branch points. The exact current graph is defined by typed artifact edges; numeric step labels are historical aliases rather than dependency authority. See the [semantic stage map](../../src/emrys/contracts/STAGE_MAP.md). |
| **DICT** | format | Sequence dictionary sidecar for a reference FASTA, containing ordered contig identity and length metadata used by GATK-era tooling. EMRYS validates agreement with FASTA, FAI, GTF, BED12, and STAR metadata rather than regenerating it during inspection. See the [reference-provenance owner](../../src/emrys/evidence/reference_provenance/README.md). |
| **DP** | field | **Depth**, the total read count used with alternate depth in EMRYS Step `08`/`09` tables. AF must reconcile with AD/DP where present. See the [Step `09` implementation](../../src/emrys/analyses/paired_cmh_candidate_ranking/step_09_cmh_editing_site_calling.R). |
| **dry-run / execute** | operation | Dry-run validates and prints the resolved plan without publishing final outputs; execute performs the declared work and publication. Dry-run success is not runtime evidence. See the [no-write and publication boundaries](../../src/emrys/orchestration/run_coordinator/CONTRACT.md#no-write-and-publication-boundaries). |
| **evidence ceiling** | evidence state | The strongest claim supported by a check or artifact. Local fixtures, real-runtime work, scheduler execution, institutional-site evidence, scientific review, and biological interpretation are distinct levels. See the [test evidence boundary](../design/TEST_BASELINE.md#evidence-boundary). |
| **evidence state** | project contract | A deliberately separated claim about implementation, testing, runtime, cluster execution, or computational completion. Moving one dimension does not promote another or establish an external scientific or biological interpretation. See the [test evidence boundary](../design/TEST_BASELINE.md#evidence-boundary). |
| **execution profile** | project contract | Optional Project-local or absolute configuration for resources and direct/Slurm placement. It does not contain scientific inputs or runtime acquisition policy. See [Profiles and immutable planning](../../src/emrys/orchestration/run_coordinator/CONTRACT.md#profiles-and-immutable-planning). |
| **FAI** | format | **FASTA index**, a text sidecar recording ordered sequence names, lengths, and byte offsets. EMRYS compares its contig names and lengths with the FASTA and DICT. See [Treat FASTA sidecars as Step `00c`](../design/decisions/scientific-pipeline.md#treat-fasta-sidecars-as-step-00c). |
| **FASTA** | format | A reference sequence text format named for the FASTA software family; EMRYS does not expand it as an acronym. The declared FASTA anchors reference identity, and its sidecars and annotations must reconcile to its contig universe. See [Use the Novogene-provided reference](../design/decisions/scientific-pipeline.md#use-the-novogene-provided-reference). |
| **FASTQ** | format | A sequence-read format carrying base calls and per-base quality characters. EMRYS accepts explicit paired R1/R2 FASTQ inputs from the sample manifest; filenames do not define pairing. See the [configuration guide](../../configs/README.md). |
| **FDR** | method | **False discovery rate**. In the Step `09` column `cmh_fdr_bh`, it is the BH-adjusted CMH p-value across the declared tested family, not a claim that the candidate is true or biologically validated. See [Use one paired CMH and global BH family](../design/decisions/scientific-pipeline.md#use-one-paired-cmh-and-global-bh-family). |
| **`FWD_like` / `REV_like`** | project contract | Neutral labels for mechanically separated read-orientation groups. They are not transcript-strand, biological sense/antisense, or validated editing-direction labels. See [Separate mechanical orientation from biological strand](../design/decisions/scientific-pipeline.md#separate-mechanical-orientation-from-biological-strand). |
| **GATK** | tool | **Genome Analysis Toolkit**. EMRYS uses its RNA-seq-oriented operations and reference conventions in bounded stages such as `SplitNCigarReads`; availability or a version check is not proof that a stage ran. See the [Step `05` owner](../../src/emrys/stages/split_n_cigar/README.md). |
| **GTF** | format | **Gene Transfer Format**, the declared gene/transcript annotation used to derive BED12 and annotate candidates. EMRYS records its provenance and checks contig agreement; it does not infer annotation identity from filenames. See [Generate BED12 from GTF](../design/decisions/scientific-pipeline.md#generate-bed12-from-gtf). |
| **HPC** | operation | **High-performance computing**. In EMRYS this usually refers to the CSU cluster environment where heavy work runs through Slurm jobs, not on the login node. See [Inspecting a Slurm Run](../operations/RUNBOOK.md#inspecting-a-slurm-run). |
| **HTML** | format | **HyperText Markup Language**, the static report-bundle output. Rendering projects the canonical summary and does not run analysis or promote evidence. See the [reporting owner](../../src/emrys/reporting/README.md). |
| **implemented locally** | evidence state | The behavior exists in local source history. This phrase alone makes no claim about fixture tests, real runtime, cluster execution, scientific review, or biological interpretation. See the [evidence guard](../../AGENTS.md#evidence-guard). |
| **JSON / JSON Schema** | schema | **JavaScript Object Notation** and its machine-readable validation vocabulary. EMRYS's versioned closed JSON Schemas define structured artifact and orchestration contracts; schema validity does not prove computation or science. See the [schema index](../../src/emrys/contracts/schemas/README.md). |
| **locally fixture-tested** | evidence state | Focused local checks passed using tiny synthetic fixtures, mocks, or test doubles as declared. This is neither real-runtime testing nor cluster proof. See the [evidence guard](../../AGENTS.md#evidence-guard). |
| **manifest** | project contract | An explicit table that declares identities, ordering, pairing, partitions, or other repeated inputs. The sample manifest owns sample metadata; the partition manifest owns Step `07` selection. EMRYS does not infer these facts from filenames or globs. See [Explicit manifests](../design/decisions/repository-and-delivery.md#explicit-manifests). |
| **mechanical orientation** | project contract | A grouping derived from alignment flags and the provisional orientation policy. It remains distinct from library strandedness, transcript strand, and biological sense/antisense interpretation. See [Separate mechanical orientation from biological strand](../design/decisions/scientific-pipeline.md#separate-mechanical-orientation-from-biological-strand). |
| **NA** | project contract | A literal sentinel used by exact TSV contracts for a field-specific missing, unavailable, or not-applicable value. The owning contract determines which meaning is allowed; `NA` is not interchangeable with zero or an empty field. See the [scientific-evidence contract owners](../../src/emrys/contracts/scientific_evidence/README.md). |
| **NCBI** | source | **National Center for Biotechnology Information**, the external archive/provider named in EMRYS's deferred public reference and read-acquisition plan. NCBI acquisition is not part of the current implemented workflow. See [`FUT-DATA-02`](../tasks/backlog_matrix.md#platform-operation-and-portability). |
| **no-clobber** | operation | A publication rule that refuses to overwrite an incompatible existing final artifact or transaction. Compatible, explicitly supported upgrades remain separate contract cases. See [Publish validated transactions](../design/decisions/execution-evidence-and-reporting.md#publish-validated-transactions). |
| **EMRYS** | project contract | The repository and application name for this evidence-bound RNA-seq candidate workflow. The name expands to **Epic Molecular Read Yield System**. See the [project overview](../../README.md). |
| **owned lock** | operation | A lock whose creator records and verifies ownership before cleanup. If ownership or rollback cannot be proved, EMRYS preserves the lock and recovery evidence instead of guessing. See [Publish validated transactions](../design/decisions/execution-evidence-and-reporting.md#publish-validated-transactions). |
| **PDF** | format | **Portable Document Format**, retained for declared Step `09` scientific-analysis plots. PDF is not a run-report format, and a valid plot file is not computational or scientific proof by itself. See the [reporting owner](../../src/emrys/reporting/README.md). |
| **Picard** | tool | A Java-based genomics toolkit used by EMRYS for duplicate marking and metrics. The current policy marks duplicates rather than removing them. See [Mark rather than remove duplicates](../design/decisions/scientific-pipeline.md#mark-rather-than-remove-duplicates). |
| **processing Run** | project contract | A complete Run ending after evidence-complete per-sample processing through Step `06`; a later compatible Run may reuse its admitted artifacts for downstream analysis. See [Processing reuse and provider boundary](../../src/emrys/orchestration/run_coordinator/CONTRACT.md#processing-reuse-and-provider-boundary). |
| **Project** | project contract | The user-facing root containing `project.yaml` and EMRYS-owned `runs/`, `logs/`, and `runtime/`, while referencing source inputs in place. It supplies one shared Dataset and Reference plus one or more named Analyses. See the [public application model](../architecture/ARCHITECTURE.md#public-application-model). |
| **provenance** | project contract | Recorded origin and identity evidence such as explicit paths, hashes, source/release metadata, producer identity, and Attempt history. A filename or colocated directory alone is not provenance. See the [reference-provenance owner](../../src/emrys/evidence/reference_provenance/README.md). |
| **QC** | method | **Quality control**, a measured check or metric on data or execution. QC can expose integrity, mapping, orientation, or duplication evidence; passing QC does not by itself prove the complete workflow or a biological conclusion. See [Keep QC and downstream transformation as separate consumers](../design/decisions/scientific-pipeline.md#keep-qc-and-downstream-transformation-as-separate-consumers). |
| **R1 / R2** | scientific term | The first and second reads, or mates, of one paired-end sequencing fragment. The sample manifest declares each pair; EMRYS does not infer pairing from filenames. See the [configuration guide](../../configs/README.md). |
| **real-runtime tested** | evidence state | The relevant non-mocked runtime and dependencies executed against declared local test inputs. It remains distinct from cluster execution, production data, scientific review, and biological validation. See the [evidence guard](../../AGENTS.md#evidence-guard). |
| **receipt / receipt-last publication** | project contract | A deterministic summary or receipt published only after all other members of a multi-file transaction validate. Its presence marks transaction completion; it does not prove the scientific meaning of the contents and must still be re-admitted. See [Publish validated transactions](../design/decisions/execution-evidence-and-reporting.md#publish-validated-transactions). |
| **renv** | tool | The R dependency-environment manager used only through EMRYS's opt-in repository activation. Restoration is explicit; scripts and tests must not bootstrap packages. It is a tool name, not an EMRYS acronym. See [Runtime, storage, and repair](../design/decisions/execution-evidence-and-reporting.md#runtime-storage-and-repair). |
| **Results** | project contract | The read-only home of completed scientist-facing outputs and reports retained with a Run. Presence alone does not establish admitted completion. See [Resume, inspection, Results, and reporting](../../src/emrys/orchestration/run_coordinator/CONTRACT.md#resume-inspection-results-and-reporting). |
| **RG / read group** | field | SAM/BAM header and record metadata that binds alignments to the declared sample, library, and platform identity. EMRYS validates the `@RG` header and per-record `RG` tag; it is unrelated to `FWD_like`/`REV_like` mechanical orientation. See [Make Step `02` the canonical BAM boundary](../design/decisions/scientific-pipeline.md#make-step-02-the-canonical-bam-boundary). |
| **RNA editing** | scientific term | A post-transcriptional RNA sequence change relative to the encoded reference. EMRYS ranks sequencing-derived candidates; its computational outputs are not by themselves validated editing events. See the [evidence and external-interpretation boundary](../design/decisions/execution-evidence-and-reporting.md#evidence-and-external-interpretation). |
| **RNA-seq** | scientific term | **RNA sequencing**. EMRYS is a manifest-driven RNA-seq candidate workflow spanning reference preparation, alignment, QC, candidate ranking, and reporting. See the [scientist-facing workflow](../architecture/ARCHITECTURE.md#scientist-facing-workflow). |
| **rollback** | operation | Restoration of the prior published state after a failed multi-file publication attempt. Incomplete rollback is an unsafe recovery state whose locks and evidence must be preserved. See [Publish validated transactions](../design/decisions/execution-evidence-and-reporting.md#publish-validated-transactions). |
| **RSeQC** | tool | **RNA-seq Quality Control**, the toolkit used for mechanical library-orientation fractions. Its labels and fractions do not by themselves establish biological sense/antisense. See the [Step `03` owner](../../src/emrys/evidence/rseqc_orientation/README.md). |
| **Run** | project contract | An immutable, normalized, identity-bound scientific and computational plan. Changing bound content creates another Run; retrying an unchanged plan creates another Attempt. See the [public model and admission contract](../../src/emrys/orchestration/run_coordinator/CONTRACT.md#public-model-and-admission). |
| **runtime inventory** | project contract | The single Project-owned admission record for already selected tools and libraries. Users do not weaken or hand-author it to make readiness pass. See [Runtime, storage, and repair](../design/decisions/execution-evidence-and-reporting.md#runtime-storage-and-repair). |
| **runtime validation blocked** | evidence state | Required runtime validation could not complete because a named dependency or environment condition prevented evaluation. This is neither a pass nor proof of computational failure. See the [evidence guard](../../AGENTS.md#evidence-guard). |
| **SAM** | format | **Sequence Alignment/Map**, the text alignment format corresponding to BAM. EMRYS avoids large default SAM outputs and publishes the declared canonical BAM/BAI boundary instead. See the [built-in workflow](../../README.md#built-in-workflow). |
| **samtools** | tool | The alignment-file toolkit used for sorting, read-group handling, indexing, splitting, querying, and integrity checks. It is a tool name, not an acronym. See the [canonical-BAM owner](../../src/emrys/stages/canonical_bam/README.md). |
| **schema** | schema | A versioned, closed machine contract for allowed structure and values. Passing schema validation establishes conformance to that structure, not computation, scientific review, or biological validity. See the [schema index](../../src/emrys/contracts/schemas/README.md). |
| **SHA-256** | method | **Secure Hash Algorithm 256-bit**, used to bind files and contracts to exact bytes. A matching hash establishes byte identity for the compared object, not correctness or scientific validity. See the [evidence and external-interpretation boundary](../design/decisions/execution-evidence-and-reporting.md#evidence-and-external-interpretation). |
| **Slurm** | tool | The **Slurm Workload Manager**, used by EMRYS's private whole-Run transport to place one grouped Run operation inside one allocation. The retained private batch bootstrap admits the job and delegates to grouped Run control; owner-local scheduler wrappers are not a supported surface. See [Inspecting a Slurm Run](../operations/RUNBOOK.md#inspecting-a-slurm-run). |
| **SNV** | scientific term | **Single-nucleotide variant**, a record with one reference base and one alternate base. Step `08` counts and excludes unsupported non-SNV alleles rather than silently coercing them. See [Consume only declared Step `07` transactions in Step `08`](../design/decisions/scientific-pipeline.md#consume-only-declared-step-07-transactions-in-step-08). |
| **SRA** | source | **Sequence Read Archive**, NCBI's sequencing-read archive and a deferred EMRYS read-acquisition source. Any SRA-to-FASTQ materialization belongs to a separate future adapter, not the current pipeline. See [`FUT-DATA-02`](../tasks/backlog_matrix.md#platform-operation-and-portability). |
| **staging** | operation | Writing a run-token-specific temporary replacement before validation and publication. A staged file is not a final output or completion marker. See [Publish validated transactions](../design/decisions/execution-evidence-and-reporting.md#publish-validated-transactions). |
| **STAR** | tool | **Spliced Transcripts Alignment to a Reference**, the aligner and genome-index format used in Steps `00a` and `01`. EMRYS validates the declared index and output set separately from tool availability. See the [semantic stage map](../../src/emrys/contracts/STAGE_MAP.md). |
| **transaction** | project contract | A coupled set of outputs that is validated and published as one recoverable unit, with its receipt or summary last. Individual member presence does not establish transaction completion. See [Publish validated transactions](../design/decisions/execution-evidence-and-reporting.md#publish-validated-transactions). |
| **TSV** | format | **Tab-separated values**, the preferred explicit table format for manifests, receipts, and deterministic projections. Each consumer owns an exact header and field contract; “TSV” alone does not imply interchangeability. See [Explicit manifests](../design/decisions/repository-and-delivery.md#explicit-manifests). |
| **UTF-8** | format | **Unicode Transformation Format, 8-bit**, the required text encoding for deterministic EMRYS JSON/TSV and report inputs where specified. Encoding conformance does not establish semantic validity. See the [schema index](../../src/emrys/contracts/schemas/README.md). |
| **VCF** | format | **Variant Call Format**, the declared multi-sample variant and candidate interchange used between Steps `07` and `08`. EMRYS validates headers, sample order, selectors, counts, and hashes before semantic parsing. See [Consume only declared Step `07` transactions in Step `08`](../design/decisions/scientific-pipeline.md#consume-only-declared-step-07-transactions-in-step-08). |
| **YAML** | format | **YAML Ain't Markup Language**, the serialization used for scientist-authored `project.yaml` and execution profiles. Repeated sample and partition metadata remains explicit TSV rather than inferred from filenames. See the [configuration guide](../../configs/README.md). |

## Coverage and update rule

Candidate discovery scans tracked documentation and public interfaces for
recurring abbreviations and project language. The glossary intentionally
excludes task IDs, fixture/sample IDs, file-local constants, shell variables,
generic syntax tokens, and ordinary filenames unless they have a distinct
maintainer-facing meaning. It also does not copy complete schema enums or
field rosters; the versioned schemas remain authoritative.

Add or revise an entry when a term recurs across owners, appears in a public
interface, or can plausibly be mistaken for a stronger evidence or scientific
claim. Verify the meaning against the canonical document, schema, or
implementation; keep the entry concise and alphabetized; add only selective
inbound links where the term otherwise blocks understanding; and run the
documentation gate. Put procedures in the runbook, checkout state in live Git,
validation observations in exact checks and retained artifacts, accepted work
in the findings matrix, and scientific policy in the decision owner rather
than duplicating them here.
