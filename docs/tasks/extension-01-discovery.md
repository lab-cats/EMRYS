## Scientific and execution boundaries

The unselected gene-tally proposal used GTF **exon-derived transcript spans**,
including introns, rather than GTF gene/transcript feature boundaries. Step 08
orientation remains provisional; missing (`NA`) or multiple gene assignments and
the same allele in both orientation tables need an explicit method. The proposed
`A;B`, `A`, `NA` example yielding A=2/B=1/NA=1 is a candidate oracle only. Selection
must settle missing/multiple genes, threshold, sorting, header-only output,
UTF-8/newlines and low-depth/non-PASS/untested/intronic rows. Real overlapping-GTF
behavior and synthetic `GENEPLUS1`/`GENEMINUS2` expectations were not executed;
semicolon/NA representation remains unresolved. No Step 08 redesign follows.

The current v2 extension slots are Step 09 and optional Step 10. Native TSV plus
a seven-column validation report use declared paths rooted by `{analysis_id}`;
all declared outputs are required. Use a distinct owner to avoid built-in
prepublication keys; that requirement is not a proven reserved-name admission
rule. The worker publishes native outputs before its independent validator.
Nonzero validation or failed rows prevents a verified Task but can leave already
committed native outputs, so it is not automatically safe to retry. Preserve
producer/validator separation, descendants, claim ownership and recovery evidence.

## Reporting and identity boundaries

A new report readmits the selected Analysis and reporter; a retained complete
report verifies existing bytes without invoking today's reporter, while Analysis
readmission still applies. Reporter changes in an Analysis-owned tree can therefore
block retained reuse. Separate reporter identity was exercised above; metadata-only
entry-point removal is a different case. `--no-report` and later installation do
not bypass Analysis identity. Reporter module ID matching is not version negotiation.

Reporter snapshots can contain all variable TSV rows. Every extra input must be
declared and hashed; generic inventory checks do not independently recompute an
external scientific result or prove a hand-written inventory exhaustive. Summary
publication and HTML publication are two immutable transactions with different
commit/recovery points; failure before/after HTML start is different. Scientific
work can be complete while reporting is blocked.

Built-in Step 09 reconciliation uses four CMH artifacts. Step 10 reconciliation
also binds context sources, four outputs and receipts; `.previous`/context-lock
assumptions need review for an external step. Removing a missing-adapter error or
falling back to generic inventory would weaken science checks. Preserve source
hashes, sample order, receipt graphs, first publication and retained re-entry.
Core package hashing also intentionally couples built-in support bytes to other
Analysis Runs; changing that policy is a separate identity decision.
