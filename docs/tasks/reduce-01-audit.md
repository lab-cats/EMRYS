## Process proportionality: primary audit lens

The earlier passes overemphasized dead code, duplicate lines, and whether each existing check protects a distinct boundary. **Reachable, correct, separately tested code may still implement a process whose benefit does not justify its cost for EMRYS.** The audit must therefore compare the *whole supported workflow* with a smaller product policy, including code, tests, schemas, documentation, operator steps, mutable state, failure and recovery paths, and runtime work. A gross owner size is an inspection envelope, never an estimated saving. Exact savings require a caller-complete replacement design and diff.
