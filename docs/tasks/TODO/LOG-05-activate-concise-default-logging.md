# LOG-05 — Activate concise default logging

## Objective

Make the approved concise console level the default after every applicable
domain has adopted and proven the two-sink contract.

## Why this exists

Changing the default before full adoption would make output inconsistent and
could hide unmigrated recovery information. Activation is therefore a separate
public-contract migration after the foundation and local rollout.

## Fixed decisions

- Default output is relatively quiet and directly relevant; explicit verbose
  and debug behavior remains available.
- Durable logs remain complete at every console level.
- Default activation cannot change artifacts, evidence, transaction behavior,
  or exits.
