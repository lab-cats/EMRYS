# Task planning

[`backlog_matrix.md`](backlog_matrix.md) is the repository's only backlog. It
owns accepted IDs, status, Importance, Complexity, required outcomes,
acceptance, and terminal dispositions. It has no blocker graph and grants no
implementation, publication, cluster, destructive, scientific-review, or
evidence-promotion authority.

Select one accepted row or state one explicitly bounded objective, then follow
the [`workflow kernel`](../operations/WORKFLOW.md). Complete, retire, absorb, or
discard an item only after its outcome, evidence at the correct level, affected
contracts/docs, and terminal disposition are recorded. Git history—not a
parallel card registry, campaign ledger, or handoff document—retains superseded
planning and chronology.
