# Architecture diagrams

These tracked Mermaid sources are concise, non-authoritative views of the
implemented system:

- [`current_user_pipeline.mmd`](current_user_pipeline.mmd) shows the readable
  scientist-facing phases.
- [`pipeline.mmd`](pipeline.mmd) shows how the public model reaches scientific
  owners and Results.
- [`reliability.mmd`](reliability.mmd) shows execution, publication, failure,
  and resume boundaries.

Use [`ARCHITECTURE.md`](../ARCHITECTURE.md) for the conceptual model and the
adjacent owner contracts for exact behavior. Accepted future work lives only
in the [backlog matrix](../../tasks/backlog_matrix.md).
