# Scientific review-package tests

This directory protects Step 09c input and evidence policy, thirteen-output
publication, locking, rollback, recovery, signal handling, and failure
behavior. `build_fixture.py` creates the suite's synthetic package inputs; the
shell and Python tests exercise the public launcher and owner.

The
[production README](../../../src/norad/evidence/assemble_scientific_review_evidence_package/README.md)
owns commands, hazards, and the exact evidence ceiling. Fixture completion is
local contract evidence, not scientific approval, validated editing sites, or
biological readiness.
