# Analysis tests

[Paired-CMH tests](paired_cmh_candidate_ranking/README.md) cover the built-in
`rank_cohort_candidates_with_paired_CMH` analysis, historically Step 09, and
its scientific-context projection. They include an independent numerical oracle
and guarded real-R cases.

Methods and supported commands belong to the
[analysis owners](../../src/emrys/analyses/README.md). The shared
[test evidence limits](../README.md#evidence-limits) apply.
