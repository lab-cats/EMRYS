# Artifact-contract fixtures

This directory owns tracked documents used by the artifact-contract suite.
Artifact-record, scientific-review-record, and run-summary v1 fixtures live
under [`artifact_schema_v1/`](artifact_schema_v1/README.md). The active report
receipt fixture is [`report_receipt_v2.json`](report_receipt_v2.json).

Fixtures are literal reviewed inputs, not generated output or evidence that a
real artifact exists. Their interpretation and failure protection remain with
the [artifact-contract tests](../README.md).
